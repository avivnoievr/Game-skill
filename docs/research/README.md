plan they followed. They are kept as-is for transparency: claims tagged [UNVERIFIED], [secondary] or
[judgment] were not confirmed against a primary source by the agent that wrote them. Paths such as
`SCRATCH/...` refer to the temporary build environment and do not exist in this repository.
