# Research reports

The five reports that informed this plugin, written by research subagents on 2026-10-09, plus the research
plan they followed. They are kept as-is for transparency: claims tagged [UNVERIFIED], [secondary] or
[judgment] were not confirmed against a primary source by the agent that wrote them. Paths such as
`SCRATCH/...` refer to the temporary build environment and do not exist in this repository.

| File | Topic |
|---|---|
| 00-research-plan.md | The plan, rules and agent roster |
| 01-ecosystem-orchestration.md | Existing Claude Code game skills/plugins, multi-agent evidence, official formats |
| 02-3d-modeling.md | What makes LLM-built 3D models good; budgets; validation |
| 03-art-animation.md | Art direction, "AI look" tells, lighting/post, animation and game feel |
| 04-qa-rigor-architecture.md | Verification loops, rigor phrasing evidence, architecture |
| 05-mcp-tools.md | Blender/engine MCP servers, CLI toolchain, 3D generation services |

Note: YouTube and most video-transcript sites were blocked in the research environment, so no videos
were watched; where a talk mattered, the agents used its slides, code or written notes instead.

Round-two reports and the original Claude handoff are in `round2/`. Current verified continuation
results live in [../VALIDATION.md](../VALIDATION.md); archived reports retain their original caveats
and may describe unfinished work or facts superseded by current documentation.
