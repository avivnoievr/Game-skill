# Reconciled opening-plan pilot

**PROVISIONAL / evaluation only.** This combines `startup-research.md` and `startup-plan-draft.md`.
It is a demonstration of the two-role mechanism, not an approved plan for the user's actual game.
Godot 4.6.3 / desktop / third-person are test assumptions; the real project was not supplied.

## Direction and slice

Use **exaggerated domestic slapstick** as the first hypothesis to test: familiar household objects,
authored rounded proportions, restrained matte materials, clear contact and responsive controls with
expressive comic recovery. Simulation mechanics do not require photoreal visuals. The researcher
inspected four creator/publisher text sources; the visual recipe remains unvalidated by images/footage.

Keep a stable costume/silhouette identity across two adjacent ages. Growth changes body proportions,
reach and locomotion instead of merely multiplying the entire model scale. A one-room slice should
prove move/interact → growth → slapstick action → discovery of one improbable domestic weapon and
one representative action beat → success/restart. If action escalation is outside the user's first
slice, defer it explicitly; the planner's original draft deferred guns, so this is a scope choice
the director must reconcile rather than silently lose part of the pitch.

| Integrated slice | Independent acceptance on one revision | Art critic + playtest QA | Applicable visual thresholds, feature evidence, errors and budgets; two repair rounds maximum |

Three concurrent specialists maximum; one writer per file/live scene. Architecture keeps growth state
separate from presentation; stage profiles coordinate rig/clip mapping, collision, reach and camera.
Choose a compatible shared rig or explicit stage swap from real source evidence. Do not assume one
uniform scaling operation can produce credible age progression.

## Prerequisites and next step

This plan cannot authorize production while actual engine/project, visual preference, source feasibility
and numerical device/asset budgets remain unresolved. It is usable for the next read-only audit and
representative source check. No game or assets were built from it and no art/QA acceptance passed.
Later ages, additional environments, open-world systems and content volume remain deferred.
